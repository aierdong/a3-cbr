# Product Overview

updated_at: 2026-04-28

## Product Purpose

本项目面向门店、督导、品牌运营管理者和平台管理员，围绕 A3 辅导场景构建一套可沉淀、可检索、可推荐的案例知识系统。产品核心不是单纯记录工单，而是把一次次门店经营辅导转化为结构化案例资产，并在同类问题再次出现时提供可追溯的历史经验参考。

长期愿景以“发现问题 -> A3 辅导执行 -> 知识沉淀 -> AI 推送 -> 行业聚合”为闭环。MVP 阶段先验证案例入库、结构化、向量检索、相似案例推荐和基础反馈这条最小闭环。

## Core Capabilities

- **A3 案例管理**：支持围绕背景、现状、目标、根因、对策、计划、效果确认、标准化等 A3 步骤沉淀案例。
- **案例知识化**：将辅导过程中的问题描述、门店/品牌信息、问题类型、上下文、根因、解决步骤、效果结果和标签转为结构化知识条目。
- **相似案例推荐**：结合结构化过滤、语义召回、重排和推荐解释，返回 Top-K 相似案例与可操作建议。
- **反馈闭环**：记录推荐结果的有用/无用、评分和采纳情况，为后续召回权重与排序优化留下依据。
- **行业知识资产演进**：长期支持从品牌知识库中筛选、脱敏和聚合优质案例，形成行业级经验库。

## Target Use Cases

- 督导在巡检或经营辅导中发现门店问题，按 A3 模板完成辅导并形成可复用案例。
- 门店或督导输入新问题后，系统检索历史相似案例，提供推荐理由、改善步骤和案例索引。
- 品牌运营管理者维护品牌内部案例资产，沉淀可复用的经营改善经验。
- 平台管理员长期从多品牌案例中聚合优质方案，建设脱敏后的行业场景方案库。

## MVP Boundary

MVP 只覆盖能验证检索推荐质量的最小产品闭环：

- A3 案例创建、编辑、详情和列表查询。
- 案例字段结构化存储。
- 摘要、标签、结构化提取和推荐文案生成。
- 云端 embedding 生成、PostgreSQL + pgvector 入库和 Top-K 检索。
- 案例推理引擎对召回结果进行重排、组装和解释。
- 基础后台页面与基础反馈记录。

MVP 暂不包含复杂多轮问答、Agent 编排、自动工单流转、外部系统双向写入、复杂规则引擎、多模态分析、训练平台、离线特征工程平台、经营数据看板、行业库审核和跨品牌脱敏工作流。

## Value Proposition

本项目的价值在于把”辅导经验”从一次性记录变成可复用知识资产。与普通 RAG 知识库不同，案例需要保持完整上下文，并同时依赖结构化字段和语义检索：结构化字段负责品牌、业态、区域、门店类型、问题类型等过滤；语义召回负责找到表达不同但本质相近的问题；检索编排与 LLM 负责解释相似性、适配历史解法并生成可追溯建议。

推荐结果必须可解释、可追溯，不能只给黑盒答案。LLM 可以帮助摘要、结构化、标签建议和推荐文案生成，但不承担主检索职责。
